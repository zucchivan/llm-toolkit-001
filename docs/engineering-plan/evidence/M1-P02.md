## Obligation map and effect boundary

| Obligation | Production owner / caller | Allowed effect | Planned refusal / proof |
| --- | --- | --- | --- |

| Guest-coordinate `ExecutionEnv` | `src/sandbox/guest-env.ts` implements the pinned `ExecutionEnv`; future production consumer is `src/engine/harness.ts:369` via `ConversationKit` role setup in `src/engine/conversations.ts` | Guest paths and calls over the stream; P02 does not change the harness factory | Verify path resolution remains in guest coordinates and namespace ID is stable for the lease |

| Reader identity and lifecycle | Helper's lease-local handle table; `read` calls binary reader `info/read/scanLines/close`; adapter also covers line and directory readers | Handle use in its creating lease; explicit close, cancellation or lease cleanup closes resources | Stale, cross-kind, unknown or post-close handles fail closed; cleanup revokes all handles |

| Process output and cancellation | Helper's fixed `exec` op and `cancel` op | `implementer` may run bash strings; command roles use literal argv; recipe-role output is bounded per stream; abort waits for helper operation settlement | Keep stdout/stderr stream identity; reject shell strings for non-coding roles; kill command tree on abort, close/revoke on cleanup |
| API documentation | `docs/api-map.md` and this packet evidence | Documentation only | Every pinned env method maps to a tested operation or documented `not_supported` result |

P02 has no host-journaled effect phase: it adds no lease launcher, filesystem
import, candidate publication, or production sandbox selection. Guest
filesystem mutations and command effects can still occur, as detailed below;
uncertain effects require lease fencing before any result can be trusted. Test
execution is confined to an explicitly created temporary fixture directory.
In production, the helper and its `NodeExecutionEnv` must be started inside a
later packet's guest; P02 fixture results do not certify containment.

## Effect and cancellation table

| Phase | Observed resource | Allowed next action | Forbidden action |
| --- | --- | --- | --- |
| Stream created / handshake pending | Fixed protocol version, lease identity and known role | Validate handshake, then accept fixed opcodes | Dispatch unknown role/opcode or treat stream bytes as authority |
| Operation in flight | One request ID, operation controller and any lease-local handles | Match response/event frames to that ID; complete, or send cancellation and await operation settlement | Accept unsolicited response IDs, allow another lease's handle, return before a canceled process is fenced |
| Helper closing / closed | In-flight operation set, handles, staged upload buffers, child processes | Abort and await commands, close all handles, drop staged buffers, clean the environment, close stream | Reuse stale handles or spawn after cleanup |
| Write/append staging | Lease-local upload buffer and target path; target is unchanged until `*.commit` | Send bounded chunks, then commit; abort drops the staged buffer | Apply partial bytes to the target or treat a missing commit response as proof of rollback |
| Committed filesystem mutation | Guest file state may have changed before the caller receives its final response; cancellation cannot roll back an already committed write | If the response is lost or the lease is canceled after commit, fence/quarantine the lease and do not import its result until a later lifecycle boundary can establish the state | Retry blindly or import an uncertain guest result |
| Command spawn/output | Child process tree, stdout/stderr frames, and request ID | Preserve literal argv or the implementer bash string; on cancel/cleanup await helper settlement and child-tree fencing | Return cancellation as complete before settlement; trust command effects after transport loss without fencing the lease |

`npm test -- test/guest-env.test.ts -t 'uses a changed cwd for guest-relative files and default command execution'`.
The original cwd red exited 1 with `permission_denied`; the expansion negative
control exited 1 when the command could not start; after restoring both fixes,
the command exited 0 (1 test passed, 11 skipped).
Tests otherwise grew in vertical slices against public
`GuestEnv`/helper behavior and the real registered pi-durable tool definitions.

environment surface and P02 disposition.

that boundary.
