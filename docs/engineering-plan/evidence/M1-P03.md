| Durable phase | Observed resource | Allowed next action | Forbidden action |
| --- | --- | --- | --- |
| `intent` committed; no cgroup observed | Host-owned durable lease journal keyed by one fresh lease UUID; no cgroup child required to exist yet | On reopen, inspect only the exact UUID-derived child; if absent, record terminal `not-launched`/recovery result and permit a new fresh UUID after receipt | Launch before intent commit; infer launch from a guest manifest; reuse this UUID for another child |
| `cgroup-created`; launch not recorded | Exact child path under the delegated cgroup parent; `cgroup.events`, `cgroup.procs`, `cgroup.kill` | Record launching before launch; use the approved Rust clone3(CLONE_INTO_CGROUP) gate with the already-opened exact child; prove placement before executable/project instructions run (later Rust amendment) | Spawn project code outside the child; accept a PID-only fence; delete/reuse the cgroup while state is uncertain |
| `launching`; no trusted acknowledgement | Exact cgroup identity plus bounded control stream and launcher process identity; guest claims are untrusted | On reopen/timeout/controller death, write `1` to this exact `cgroup.kill`, wait for `populated 0`, then mark fenced; if unavailable remain recovery-required | Treat helper hello, guest manifest, pidfd/PID exit, or bwrap exit alone as proof all descendants are dead; import |
| `attached`; guest may be running | Same exact cgroup plus trusted helper handshake bound to lease UUID/role; namespace checks performed inside launched namespace | Exchange fixed protocol frames; on any uncertain transport or owner loss, kill and verify empty before later recovery | Accept a guest-supplied cgroup/fence claim; launch a second workload in the lease; use workload stdio as control channel |
| `fencing`; kill requested, not yet empty | Exact cgroup `cgroup.events` reports `populated 1` or cannot be read | Retry only the same kill/observation against the same child; remain recovery-required if capability/identity is lost | Import, remove child, replace child identity, declare success on timeout |
| `fenced`; `populated 0` verified | Exact cgroup identity and durable fence observation; no guest writer remains | Exclude all writers/reattachment, scan the full fenced projection with bounded no-follow reads, construct and durably stage the host-owned sealed result; record import intent only after sealing | Trust guest fence booleans; read mutable guest paths; import before the empty-population observation |
| `importing`; fence verified; no import receipt | Host-owned durable sealed content bound to lease/base/controls/projection and recorded destination/result identity; destination still private/unpublished | Revalidate all names/types/modes/limits/digests and atomically commit the complete validated delta; on crash re-open only the same sealed bytes or retain recovery-required | Partial import; arbitrary tar extraction; follow links; change destination; treat missing receipt as rollback |
| `imported`; result receipt not committed | Host-owned imported delta/digest and durable fence | Reconcile the same import by digest and write the missing result receipt; identical replay is idempotent | Re-run guest code, import a different manifest, publish or schedule dependent work without receipt |
| `complete`; result receipt committed | Durable receipt bound to lease UUID, manifest digest, and imported result | Return the recorded result; later work gets a fresh lease UUID | Reuse lease/cgroup or re-import changed guest bytes |
| Any phase with cgroup identity/event mismatch or unreadable state | Conflicting/missing cgroup or durable identity | Mark recovery-required; operator repairs only after independently establishing the exact process/cgroup state | PID fallback, automatic identity substitution, candidate import, or dependent work |
